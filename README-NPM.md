# Valk UI CLI

CLI interativo para instalar componentes Valk UI no seu projeto React ou Blade (Laravel).

## 📦 Instalação

```bash
# Instalar globalmente
npm install -g valk-ui

# Ou usar diretamente com npx (recomendado)
npx valk-ui
```

## 🚀 Como Usar

Execute o comando:

```bash
valk-ui
```

O CLI irá guiá-lo através de um processo interativo:

1. **Escolha o idioma**: Português, Inglês ou Espanhol
2. **Selecione a tecnologia**: React/TypeScript ou Blade/Laravel
3. **Escolha o modo de instalação**:
   - Por categoria (Forms, Feedback, Layout, Charts)
   - Individualmente (escolha cada componente)
   - Todos os componentes
4. **Selecione os componentes** que deseja instalar
5. **Defina o diretório** onde os componentes serão instalados (padrão: `./src/components/ui`)
6. **Confirme** e os componentes serão copiados para seu projeto

## 🎨 Componentes Disponíveis

### Formulários
- Button, Input, Select, Checkbox, Toggle, DatePicker

### Feedback
- Modal, StatusBadge, ProgressBar

### Layout
- Avatar, MetricCard, PaginatedTable

### Gráficos
- BarChart, DonutChart, LineChart

## 📋 Requisitos

- Node.js 16+
- Para React: React 18+ e TypeScript
- Para Blade: Laravel 10+ ou 11+
